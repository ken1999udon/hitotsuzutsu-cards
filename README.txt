ネスペイージス 第3章 Ethernet LAN — 一問一答の作成・改訂記録

このフォルダを独立したローカルGitリポジトリとして管理します。
対象は第3章の問題データ、作成方針、出典、生成スクリプト、Anki配布物です。
元の75問版は、比較と改訂経緯の確認のために残します。

元の75問版
  一問一答データ.json                  問題・解答・出典の元データ
  第3章_一問一答75問.csv              CSV版
  anki/                              初回のAnki版

改訂版（知識一覧を先に作り、問題と対応させる方式）
  revision/README.txt                作成基準・使い方・再生成・確認の方法
  revision/data/                     知識132項目・カード170枚・出典・方針
  revision/tools/                    生成とAnki本体による取り込み確認
  revision/dist/                     改訂版APKG・知識一覧CSV/HTML・検証結果

最初のコミットに元75問版、その後のコミットに改訂版を記録します。
改訂版は元版とは別デッキです。元版の学習履歴の移行は行いません。

既存Word冊子と一時確認ファイルは、このGitリポジトリの管理対象から除外します。
ファイル自体は元の場所に残します。

参照元
  https://www.infraexpert.com/info/netspecial1.html の第3章14項目
  問題文・解答文は独自に作成しています。

Gitはこのフォルダ内で利用できます。
  git log --oneline
  git status

リモートへの公開・送信は行いません。
